# 🚀 Phase 2 Execution Guide - User-Facing Filtering & Display Logic\n\n**Timeline**: Week 2 (Jan 6-12, 2025)\n**Status**: Ready to Begin\n**Date**: December 31, 2025\n**Estimated Duration**: 4-6 hours\n\n---\n\n## 📋 Phase 2 Overview\n\nPhase 2 adds filtering logic so users only see published content, while draft/archived items remain hidden.\n\n### What Gets Updated\n\n**User Pages** (What users see):\n- Quiz pages - Filter by status=published, visibility=public\n- Puzzle pages - Filter by status=published, visibility=public\n- Stories pages - Filter by status=published, visibility=public\n- Home page - Show featured items first\n\n**Admin Pages** (What admins see):\n- No change - Admins see all items including drafts\n\n**Special States**:\n- **Coming Soon**: Show teaser/badge instead of hiding\n- **Featured**: Appear first in lists\n- **Private**: Only show to owner/specific users\n\n---\n\n## 🔍 Files to Update\n\n### Step 1: Identify Query Functions\n\nFind where data is fetched for user pages:\n\n```bash\n# Search for quiz/puzzle/story queries\ngrep -r \"collection.*quiz\" src/ --include=\"*.js\" | head -20\ngrep -r \"collection.*puzzle\" src/ --include=\"*.js\" | head -20\ngrep -r \"collection.*story\" src/ --include=\"*.js\" | head -20\ngrep -r \"collection.*categories\" src/ --include=\"*.js\" | head -20\n```\n\n### Step 2: Identify Components\n\nFind components that display items to users:\n\n```bash\n# Look for pages that list content\nls -la src/pages/\nls -la src/components/\n```\n\n### Step 3: Update Query Logic\n\nWhere queries are made, add where clauses:\n\n**Current (No filtering)**:\n```javascript\nconst snapshot = await getDocs(collection(db, 'quizzes'));\n```\n\n**Updated (With filtering)**:\n```javascript\nconst q = query(\n  collection(db, 'quizzes'),\n  where('status', '==', 'published'),\n  where('visibility', '==', 'public')\n);\nconst snapshot = await getDocs(q);\n```\n\n### Step 4: Add Featured Sorting\n\n```javascript\nconst q = query(\n  collection(db, 'quizzes'),\n  where('status', '==', 'published'),\n  where('visibility', '==', 'public'),\n  orderBy('featured', 'desc'),  // Featured first\n  orderBy('createdDate', 'desc')  // Then newest\n);\n```\n\n### Step 5: Handle Coming Soon\n\nFor items with status='comingSoon':\n\n```javascript\nif (item.status === 'comingSoon') {\n  return (\n    <ComingSoonBadge item={item} />\n  );\n}\n```\n\n---\n\n## 🔄 Typical File Updates\n\n### Example: Quiz Service\n\n**File**: `src/services/quizService.js` (or wherever quizzes are fetched)\n\n**Before**:\n```javascript\nconst getAllQuizzes = async () => {\n  const snapshot = await getDocs(collection(db, 'quizzes'));\n  return snapshot.docs.map(doc => ({ id: doc.id, ...doc.data() }));\n};\n```\n\n**After**:\n```javascript\nimport { query, where, orderBy } from 'firebase/firestore';\n\nconst getAllQuizzes = async () => {\n  const q = query(\n    collection(db, 'quizzes'),\n    where('status', '==', 'published'),\n    where('visibility', '==', 'public'),\n    orderBy('featured', 'desc'),\n    orderBy('createdDate', 'desc')\n  );\n  const snapshot = await getDocs(q);\n  return snapshot.docs.map(doc => ({ id: doc.id, ...doc.data() }));\n};\n```\n\n---\n\n## 🎯 Implementation Checklist\n\n### you** with an error:\n```\nThe query requires an index. You can create it here: [link]\n```\n\nJust click the link and create the index. Firebase does it automatically.\n\n### Performance Consideration\n\nFiltering large datasets:\n- ✅ Use `where` clauses (efficient)\n- ❌ Don't fetch all then filter in JS (slow)\n\n### Private Items\n\nFor privacy:\n```javascript\nwhere('visibility', 'in', ['public', 'comingSoon'])\n```\n\nThis excludes 'private' items.\n\n---\n\n## 📝 Step-by-Step Example\n\n### Finding Files to Update\n\n```bash\n# 1.
