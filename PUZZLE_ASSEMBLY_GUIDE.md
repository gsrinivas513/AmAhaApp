# Puzzle Assembly Quiz - Step-by-Step Visual Guide

## 🎯 Quick Overview

```
STEP 1: Quiz Details
├─ Title, Category, Level, Audience
├─ Select Quiz Type: "Puzzle Assembly" ✓
├─ Set time limits, points, passing score
└─ Click NEXT →

STEP 2: Add Questions  
├─ Add Question #1
│  ├─ Add Content Items (flexible)
│  │  ├─ 📄 Text: "Arrange events chronologically..."
│  │  ├─ 🖼️ Image: Timeline graphic
│  │  └─ 📝 Text: Additional instructions
│  └─ Configure Answer
│     └─ Enter items in CORRECT order (comma-separated)
├─ Add Question #2, #3, ... (repeat)
└─ Click SAVE QUIZ
```

## 🎯 Key Difference: Puzzle Assembly vs Ordering

Both arrange items, but used for different purposes:

### ORDERING (Sequence Ordering)
- Arranging steps in a process
- Ranking by criteria (best to worst)
- Organizing timeline events
- Example: Arrange cooking steps in order

### PUZZLE (Puzzle Assembly)
- Assembling puzzle pieces
- Putting puzzle images together
- Arranging physical/conceptual pieces
- Example: Arrange puzzle pieces of a map

**In Admin:** Both ask for comma-separated items in correct order!
**For Students:** Identical UI - drag items to arrange
