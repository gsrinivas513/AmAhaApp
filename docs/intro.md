# Welcome to AmAha Documentation

AmAha is an interactive learning platform that combines quizzes, puzzles, and interactive activities to engage users of all ages. This documentation covers everything you need to understand and work with AmAha.

- **Content Structure** - Learn how content is organized in AmAha
- **User Experience** - Understand design principles and user flows
- **Admin & Content Creation** - Manage and create content
- **Architecture** - Technical deep dive into how AmAha works
