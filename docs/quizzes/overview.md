# Quiz System Overview

The Quiz System is AmAha's core learning assessment tool. It combines question variety with flexible difficulty levels to serve different learning needs.

## What is a Quiz?

A quiz is a structured learning assessment that:

- Presents questions to users
- Accepts user responses
- Validates answers immediately
- Calculates scores in real-time
- Tracks performance on leaderboards

## Quiz Structure

Every quiz has:

1. **Metadata** - Title, description, category, difficulty level
2. **Content** - Set of questions organized by difficulty
3. **Variants** - Separate question sets for each difficulty (Easy, Medium, Hard, Expert)
4. **Settings** - Scoring rules, hints, time limits

## How Quizzes Work

```
User Browsing
    ↓
Selects Quiz (clicking card or difficulty badge)
    ↓
Chooses Difficulty (Easy/Medium/Hard/Expert)
    ↓
Quiz Starts Immediately
    ↓
Answers Questions (one by one)
    ↓
Gets Instant Feedback
    ↓
Views Final Score
    ↓
Sees Leaderboard Ranking
    ↓
Option to Try Different Difficulty or New Quiz
```

## Key Characteristics

### Difficulty Variants

Every quiz has 4 difficulty levels:

| Level | Target | Question Count | Features |
|-------|--------|-----------------|----------|
| **Easy** | Foundational | 5 Q | Basic concepts, clear answers |
| **Medium** | Standard | 3 Q | Moderate difficulty |
| **Hard** | Advanced | 4 Q | Complex scenarios |
| **Expert** | Challenge | 5 Q | Advanced reasoning |

**Note:** Question counts are examples; actual counts vary by quiz.

### Immediate Feedback

- Each answer is validated instantly
- User sees if answer is correct/incorrect
- No waiting for quiz completion
- Can view explanations immediately

### Scoring

- 1 point per correct answer
- Final score = total correct answers
- Score is recorded for leaderboards
- Completion time is tracked

### Leaderboards

- Separate board per difficulty level
- Top 100+ performers displayed
- Sorted by score, then by time
- Anonymous or registered users

## Quiz Variants

Variants allow the same quiz to serve different audiences:

- **Easy Variant** - Simpler questions for beginners
- **Medium Variant** - Standard difficulty
- **Hard Variant** - Complex scenarios
- **Expert Variant** - Advanced challenges

Each variant has:
- Separate set of questions
- Own leaderboard
- Individual completion tracking
- Customizable rules
