# Content Workflow

This page describes the process for creating, reviewing, and publishing content on AmAha.

## Content Lifecycle

### State Diagram

```
[Draft] → [Submitted for Review] → [Approved] → [Published]
   ↓                  ↓                  ↓
[Archived]        [Rejected] ──→ [Revision Needed] → [Resubmitted]
```

---

## Workflow by Role

### Educators: Simple Flow

**Educators don't need approval:**

```
[Create Quiz] → [Preview] → [Publish] → [Assign to Class]
   (5 min)        (2 min)       (1 sec)      (1 min)
   ↓
[Monitor Usage & Results]
```

**No publishing delays**  
**Immediate access to own classes**  
**Edit anytime**

### Content Creators: Approval Required

**Creators need admin review:**

```
[Create] → [Preview] → [Submit] → [Admin Review]
  (varies)    (5 min)    (1 min)    (2-24 hours)
                                        ↓
                            [Approve] or [Reject]
                                ↓              ↓
                           [Public]      [Revise & Resubmit]
```

## Creating Content as Educator

### Step 1: Create in Admin Panel

```
[Admin Portal] → [Create Content]
├─ Select type (Quiz/Puzzle/Activity)
├─ Fill in details
├─ Add questions/content
├─ Configure settings
└─ [Save as Draft]
```

### Step 2: Preview

```
[Preview Your Content]
├─ See as students see it
├─ Test on mobile
├─ Try different difficulties
└─ [Edit] or [Continue]
```

### Step 3: Publish

```
[Publish Options]
├─ Status: Draft → Published
├─ Visibility:
│  ├─ Private (only you)
│  ├─ Class (your classes only)
│  └─ Public (all users)
├─ Search: Indexed or not
└─ [Publish Now]
```

**Immediately available to assigned classes**

## Creating Content as Creator

### Step 1: Create Content

```
Same as educator process, but with approval
```

### Step 2: Submit for Review

```
[Submit for Review]
├─ Title: [Content Title]
├─ Description: [Why this content?]
├─ Standards Alignment: [Select standards]
├─ Tags: [Relevant tags]
├─ Learning Objectives: [List objectives]
│
├─ Self-Assessment:
│  ├─ WCAG AA accessible: ☑ Yes
│  ├─ Factually accurate: ☑ Yes
│  ├─ Age-appropriate: ☑ Yes
│  ├─ Tested thoroughly: ☑ Yes
│
└─ [Submit to Review Queue]
```

### Step 3: Review by Admin

```
[Admin Review Interface]
├─ Reviewer assigned
├─ Review checklist:
│  ├─ ☑ Accuracy verified
│  ├─ ☑ Content quality assessed
│  ├─ ☑ Accessibility verified
│  ├─ ☑ Standards aligned
│  └─ ☑ Appropriate for grade
│
├─ Decision:
│  ├─ [Approve] → Immediately published
│  ├─ [Request Changes] → Notes provided
│  └─ [Reject] → With explanation
│
└─ [Send Review Decision]
```

### Step 4: Publishing

```
If Approved:
├─ Content automatically published
├─ Creator notified
├─ Appears in public search
└─ Can be assigned

If Changes Requested:
├─ Creator gets detailed feedback
├─ Can resubmit after edits
├─ Review happens again

If Rejected:
├─ Detailed rejection reason provided
├─ Can appeal or create new content
```

## Editing Published Content

### Educator Edits

```
Can Edit (Anytime):
✓ Description
✓ Learning objectives
✓ Tags & metadata
✓ Explanations & hints
✓ Images/media
✓ Difficulty assignments

Cannot Edit (Without Issues):
✗ Correct answers (breaks grading)
✗ Question text (changes meaning)
✗ Remove questions (breaks existing attempts)

When You Try:
├─ System warns about impacts
├─ Shows how many students affected
├─ Option to create new version
└─ Document changes in notes
```

### Creator Edits

```
Same as educators, but:
├─ Changes require re-review if major
├─ Must resubmit for approval
├─ Can keep published while reviewing
└─ Minor corrections auto-approved
```

## Quality Assurance

### Testing Checklist

Before publishing, test:

**Functionality:**
- [ ] All questions/content work
- [ ] All interactions work
- [ ] Media loads properly
- [ ] On mobile devices
- [ ] In different browsers

**Accuracy:**
- [ ] No spelling/grammar errors
- [ ] Facts verified
- [ ] Answers correct
- [ ] Explanations clear

**Accessibility:**
- [ ] Works with keyboard
- [ ] Screen reader compatible
- [ ] High contrast mode OK
- [ ] Proper heading hierarchy
- [ ] Form labels correct

**User Experience:**
- [ ] Clear instructions
- [ ] Intuitive navigation
- [ ] Appropriate difficulty
- [ ] Helpful feedback
- [ ] Load time < 2 seconds
