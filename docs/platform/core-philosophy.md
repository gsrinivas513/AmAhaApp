# Core Philosophy

AmAha is built on principles that prioritize learning, engagement, and accessibility.

## Core Principles

### 1. **No Punishment for Learning**

Users should never feel penalized for wrong answers. Learning includes making mistakes.

- Hints are available to help
- Leaderboards show achievement, not failure
- Users can retry with different difficulty levels
- Scoring emphasizes what was accomplished, not what was missed

### 2. **Choice Drives Engagement**

Users should always have control over their learning path.

- Difficulty selection before starting
- Ability to switch difficulty mid-session
- Choice of quiz topics
- Optional leaderboard participation

### 3. **Variety Prevents Boredom**

Different content types serve different learning styles.

- Multiple quiz types (MCQ, matching, drag-drop, coding, etc.)
- Puzzle activities for visual learners
- Interactive activities for hands-on exploration
- Mix of quick quizzes and longer challenges

### 4. **Immediate Feedback**

Users should know instantly how they're doing.

- Instant answer validation
- Immediate score calculation
- Real-time leaderboard updates
- Visual progress indicators

### 5. **Accessibility is Built-In**

Learning should be inclusive, not an afterthought.

- Keyboard navigation support
- High contrast options
- Responsive design for all devices
- Clear, simple language
- Alternative input methods (touch, mouse, keyboard)

### 6. **Configuration Over Code**

Content creators shouldn't need programming knowledge.

- All quiz/puzzle data defined in configuration
- No code changes needed to add content
- Flexible templates support variety
- Reusable components

## Design Values

### Simplicity
- Clean interfaces with minimal distractions
- Clear call-to-action buttons
- Straightforward workflows
- No unnecessary features

### Transparency
- Clear rules and scoring
- Visible difficulty levels
- Honest leaderboard rankings
- Honest about what each activity is

### Encouragement
- Positive messaging
- Celebration of achievement
- Support for retries
- Recognition of effort

### Respect for Time
- Quick-start options (1-click)
- Optional session lengths
- Save progress capability
- No forced engagement
