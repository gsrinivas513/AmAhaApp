# Target Audience

AmAha is designed for diverse users across age groups and learning styles.

## Primary Audiences

### Students (Ages 10+)
- Test knowledge before exams
- Practice specific topics
- Self-paced learning
- Competitive score tracking

**How AmAha Serves Them:**
- Multiple difficulty levels for progressive challenge
- Clear scoring feedback
- Leaderboards for motivation
- Instant quiz access

### Educators
- Assess student understanding
- Create subject-based quizzes
- Track learning outcomes
- Differentiate difficulty levels

**How AmAha Serves Them:**
- Admin tools for quiz creation
- Flexible question types
- Difficulty variants for all skill levels
- Analytics on quiz performance

### Casual Learners
- Brain exercises and puzzles
- General knowledge building
- Entertainment and learning mix
- Low-pressure, self-directed

**How AmAha Serves Them:**
- No time pressure (flexible timing)
- Fun puzzle activities
- Optional difficulty selection
- Non-judgmental scoring

### Kids (Ages 6-12)
- Early learning and exploration
- Letter, number, and pattern recognition
- Interactive storytelling
- Safe, fun environment

**How AmAha Serves Them:**
- Kid-friendly design (large buttons, clear text)
- Bright, engaging visuals
- Encouraging, positive feedback
- No negative consequences for wrong answers

## Accessibility Consideration

AmAha is designed to be inclusive:

- **Visual** - High contrast, readable fonts, color-blind friendly
- **Motor** - Touch-friendly, responsive on all devices
- **Cognitive** - Clear instructions, minimal distractions, straightforward flows
- **Auditory** - Text-based with optional audio support (when available)

## Usage Patterns

| User Type | Session Length | Frequency | Primary Goal |
|-----------|----------------|-----------|--------------|
| Student | 5-15 min | Daily/Weekly | Test knowledge |
| Casual | 5-10 min | Random | Brain break |
| Kid | 5-20 min | Daily | Exploration |
| Competitive | 10-20 min | Daily | High scores |
