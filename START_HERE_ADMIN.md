## 🎯 COMMON TASKS

### Add a Quiz
1. Go to Dashboard → ❓ Manage Quizzes
2. Click "➕ Add New Quiz"
3. Fill form (Title, Category, Audience, Questions, Difficulty)
4. Click "Save Quiz"

### Create a Puzzle
1. Go to Dashboard → 🧩 Manage Puzzles
2. Click "➕ Add New Puzzle"
3. Select puzzle type from 6 options
4. Configure audience and difficulty
5. Click "Save Puzzle"

### Publish a Story
1. Go to Dashboard → 📖 Manage Stories
2. Click "➕ Create New Story"
3. Enter story details (Title, Category, Chapters)
4. Select target audience
5. Click "Create Story"

## ❓ FAQ

**Q: Where do I start?**
A: Go to `/admin/modern-dashboard` and explore!

**Q: How do I add content?**
A: Click the tab for what you want (Quiz/Puzzle/Story), then click "Add New".

**Q: Why can't I see my content?**
A: Make sure it's in "Published" status, not "Draft".

**Q: How do I change the theme?**
A: Use the theme selector in the main app. Admin automatically updates!

**Q: What's the difference between Draft and Published?**
A: Draft = not visible to users. Published = visible to users.

**Q: Can I edit content after creating it?**
A: Yes! Click the "✏️ Edit" button next to any item.

**Q: How do I delete something?**
A: Click the "🗑️ Delete" button. Warning: This can't be undone!
