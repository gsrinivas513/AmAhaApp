- Set **time limits, passing scores, attempts**

### Quiz Types Supported
1. MCQ (Multiple Choice)
2. Multi-Select (Multiple Answers)
3. True/False (Boolean)
4. Fill Blank (Text Input)
5. Matching (Pair Mapping)
6. Ordering (Sequence)
7. Drag & Drop (Categories)
8. Coding (Code Submission)
9. Image-Based (Click Regions)
10. Puzzle (Story Assembly)
11. Audio-Based (Listen & Answer)

### Step 1: Create Quiz
- Fill basic info (title, category, level, type)
- Set settings (time, passing score, attempts)

### Step 2: Add Questions
- Add multiple questions
- Type-specific answer forms
- Add hints and explanations

### Step 3: Save
- Click save
- Stored in Firestore automatically
- See success message
