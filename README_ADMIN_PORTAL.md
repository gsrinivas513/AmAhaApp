## 🆘 Support & Troubleshooting

### Common Questions

**Q: How do I add a quiz?**
A: Go to `/admin/quizzes`, click "Add New Quiz", fill the form, select category and audience, click Save.

**Q: Why can't I see my content?**
A: Check if it's in "Draft" status. Only "Published" content shows to users.

**Q: How do I change themes?**
A: Use the theme selector in the main app. Admin pages automatically adapt to the selected theme.

**Q: Can I edit multiple items at once?**
A: Currently, you can edit items individually. For bulk operations, see Phase 2 enhancements.
