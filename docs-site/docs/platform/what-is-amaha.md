# What is AmAha?

AmAha is an **interactive learning platform** that helps users learn through a combination of:

- **Quizzes** - Traditional knowledge assessments with multiple question types
- **Puzzles** - Visual problem-solving activities
- **Interactive Activities** - Toy-like learning tools focused on exploration rather than punishment

## Core Concept

AmAha makes learning engaging by:

1. **Removing friction** - Quick, one-click quiz start from the listing page
2. **Providing choice** - Users select difficulty level before starting
3. **Offering variety** - Different activity types keep learning fresh
4. **Tracking progress** - Leaderboards and scoring for motivation
5. **Being forgiving** - No harsh penalties for mistakes; focus on learning

## Key Characteristics

| Aspect | Description |
|--------|-------------|
| **Platform** | Web-based application (mobile-responsive) |
| **User Focus** | Learners of all ages (kids, students, adults) |
| **Activity Types** | Quizzes, Puzzles, Interactive Activities |
| **Difficulty Levels** | Easy, Medium, Hard, Expert (all quizzes) |
| **Scoring** | Points-based with leaderboards |
| **Content Access** | Public quiz listing, instant access |

## What Sets AmAha Apart

- **Minimal UI** - Clean, distraction-free interface
- **Kid-Friendly** - Accessible design suitable for younger users
- **Configuration-Driven** - All content defined through configuration, not code
- **Extensible** - Easy to add new quiz types and puzzle categories
- **Engaging** - Multiple difficulty variants per quiz encourage mastery

## User Journey

1. Browse available quizzes
2. Click quiz card or difficulty badge
3. Select difficulty (Easy/Medium/Hard/Expert)
4. Start quiz immediately
5. Answer questions
6. View score and leaderboard
7. Option to try different difficulty or take another quiz

## Who Uses AmAha?

- **Students** - Test knowledge across subjects
- **Teachers** - Assess learning outcomes
- **Casual Learners** - Self-paced learning and brain exercises
- **Competitive Users** - Climb leaderboards and earn high scores
