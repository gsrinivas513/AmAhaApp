# Feature Summary

Here's an overview of all current AmAha features and capabilities.

## Quizzes

**What:** Traditional knowledge assessments with immediate feedback

**Key Features:**
- 11+ supported question types (MCQ, True/False, Image-Based, Audio-Based, etc.)
- 4 difficulty variants (Easy, Medium, Hard, Expert)
- Instant answer validation
- Score tracking and leaderboards
- Multimedia support (images, audio, video)
- Hints and explanations

**How Users Access:**
- Browse all quizzes on Quiz Hub
- Click quiz or difficulty badge for instant access
- Choose difficulty before starting
- Complete and view score

[Learn more about Quizzes](../quizzes/overview)

## Puzzles

**What:** Visual problem-solving activities requiring interaction

**Key Features:**
- Multiple puzzle types (Drag & Drop, Ordering, Matching, etc.)
- Difficulty-based variants
- Interactive grid and canvas-based solutions
- Immediate validation
- Customizable piece counts and complexity

**How Users Access:**
- Browse available puzzles
- Select difficulty
- Interact with pieces/elements
- Submit solution

[Learn more about Puzzles](../puzzles/overview)

## Interactive Activities

**What:** Toy-like exploratory learning tools

**Key Features:**
- No penalty for exploration
- Immediate interaction feedback
- Can be challenge or free-play mode
- Suitable for all ages
- Educational but fun

**How Users Access:**
- Browse activities
- Choose activity type
- Interact freely or complete challenge
- Optional scoring

[Learn more about Activities](../activities/overview)

## Leaderboards

**What:** Competitive score tracking

**Current Features:**
- Per-difficulty leaderboards
- Top performers displayed
- User scores and completion times
- Separate boards for different quiz types

**Future:**
- Global vs. friend leaderboards
- Seasonal/monthly rankings
- Achievement badges

## Content Discovery

**What:** How users find quizzes and activities

**Current Features:**
- Quiz listing page with cards
- Difficulty badges showing levels available
- Question count per difficulty
- Average time estimate
- Rating and play count

**Future:**
- Series/collection browsing
- Category filtering
- Recommendation engine
- Search functionality

## User Accounts

**What:** Track user progress and scoring

**Current Features:**
- User registration and login
- Score history per quiz
- Leaderboard rankings
- Session management

**Future:**
- User profiles
- Learning streaks
- Progress visualization
- Export certificates

## Admin Tools

**What:** Manage and create content

**Current Features:**
- Quiz seeding/creation
- Batch quiz operations
- Content preview
- Dashboard for management

[Learn more about Admin](../admin/overview)
