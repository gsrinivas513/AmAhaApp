# Matching Activities

Matching activities challenge users to connect or pair related items as quickly and accurately as possible.

## Overview

**Definition:** Identify relationships and connect pairs of related items.

**Interaction:** Click to select, then click match (or drag to pair)  
**Time:** 3-4 minutes  
**Scoring:** Correct matches × speed + accuracy  
**Difficulty Levels:** Easy, Medium, Hard, Expert

---

## Core Mechanics

### Setup
1. User receives **6-12 items** in two columns or mixed
2. Clear matching criterion displayed
3. Timer starts (varies by difficulty)
4. User makes connections

### Matching Criteria

**Definition:** Word ↔ Definition (Cat ↔ "Feline animal")  
**Translation:** English ↔ Spanish (Hello ↔ Hola)  
**Synonym:** Word ↔ Similar word (Big ↔ Large)  
**Category:** Item ↔ Category (Apple ↔ Fruit)  
**Cause-Effect:** Cause ↔ Effect (Rain ↔ Wet ground)  

### Validation
- User submits matches
- System validates each pair
- Partial credit possible (50% correct = 50 points)
- Instant visual feedback

## Interaction Methods

### Method 1: Click to Connect
- Click first item → Click match
- Visual line shows connection
- Correct pairs lock in place
- Continue until all matched

**Flow:**
```
[Item A] - Click → [Highlight]
             ↓
        [Item 3] - Click → [Match confirmed ✓]
```

**Best for:** Touch devices, quick interactions

---

### Method 2: Drag & Drop
- Drag item from left column
- Drop on matching item in right
- Visual feedback during drag
- Connection appears after release

**Flow:**
```
[Item A] → Drag → [Visual line] → Drop on [Item 3] → ✓ Match
```

**Best for:** Desktop, mouse users

---

### Method 3: List Selection
- Select item → Choose from dropdown
- Click confirm
- Move to next item
- Sequential matching

**Flow:**
```
[Item A] → Select → [Dropdown list] → [Item 3 selected] → Confirm ✓
```

**Best for:** Keyboard accessibility, systematic

## Scoring Formula

### Base Score
```
Correct Matches = Number of correct pairs identified
Base Score = (Correct Matches / Total Pairs) × 100
```

### Time Bonus
```
Time Bonus = Max(0, (Time Limit - Time Used) × Speed Factor)
```

### Accuracy Multiplier
```
Accuracy = Correct Matches / Total Pairs
Final Score = (Base Score + Time Bonus) × Accuracy
```

### Example Calculation
- Pairs: 10 total
- Correct: 9 matches = 90 points
- Time: 45 sec / 60 sec limit = 45 × speed = 45 points
- Accuracy: 9/10 = 0.9 multiplier
- **Final: (90 + 45) × 0.9 = 121.5 ≈ 122 points**

## Tips for Success

**For Beginners:**
- Start with definitions (most familiar)
- Take time, don't rush
- Use hints to learn relationships
- Build confidence first

**For Intermediate:**
- Try translation or synonyms
- Increase speed gradually
- Learn patterns in matches
- Track improvements

**For Advanced:**
- Challenge with Expert level
- Compete for leaderboard spots
- Mix activity types
- Aim for perfect scores
