## Preset Characteristics Explained

### Size (Brush Diameter)
- **2-6px**: Fine details, precise work
- **10-20px**: General painting, versatile
- **25-50px**: Large coverage, bold strokes

### Hardness (Edge Sharpness)
- **100%** (Hard): Sharp edges, precise outlines
- **50%** (Medium): Blended edges, natural feel
- **0-20%** (Soft): Very soft, atmospheric effects

### Opacity (Transparency)
- **100%**: Fully opaque, solid color
- **60-90%**: Semi-opaque, allows blending
- **20-50%**: Very transparent, subtle effects

### Spacing (Stamp Distance)
- **2-3px**: Smooth continuous strokes
- **5-10px**: Normal spacing, efficient
- **15-25px**: Visible stamps, stipple effect

## Tips for Using Presets

### 1. Experimenting
- Click different presets to find your style
- Combine presets (sketch with Pencil, blend with Soft Brush)
- Test on practice layer before final artwork

### 2. Combining Presets
```
Sketch:    Use HB Pencil
Block In:  Use Hard Brush
Blend:     Use Soft Brush
Refine:    Use Detail Brush
Final:     Use Ink Pen
```

### 3. Creating Your Style
- Natural Bristle + Blend Brush = Oil painting
- Calligraphy + Splatter = Artistic expression
- Marker + Watercolor = Mixed media
- Hard Brush + Dots Pattern = Stippling art

### 4. Performance Tips
- Use larger presets (20px+) for speed
- Switch to smaller presets (2-6px) for precision
- Use spacing presets for specific effects
