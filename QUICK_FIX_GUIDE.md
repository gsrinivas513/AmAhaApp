# Quick Fix: Puzzles Categories Not Loading

## TL;DR - Just Do This:

1. Go to: `http://localhost:3000/admin/normalize-features`
2. Click the green **"Start Normalization"** button
3. Wait for it to complete (shows "✅ Normalization Complete!")
4. Refresh your browser (`Cmd+Shift+R` on Mac / `Ctrl+Shift+F5` on Windows)
5. Hover over "Puzzles" in the navigation bar
6. **✅ You should now see the puzzle categories!**

---

## What It Does

The normalization tool fixes your Firestore database by:

- Converting all feature names to **lowercase**
- Fixing document IDs that are wrong
- Adding missing required fields
- Removing deprecated fields

---

## Before vs After

### BEFORE (❌ Broken)
```
Document ID: "Puzzles"
  - id field: MISSING
  - name: "Puzzles" (wrong case)
```

### AFTER (✅ Fixed)
```
Document ID: <auto-generated>
  - id field: "puzzles"
  - name: "puzzles"
```

---

## Why This Broke

The app's navigation queries for features with lowercase names like `"puzzles"` but your database had them stored as `"Puzzles"` with wrong structure. **The case mismatch prevented categories from loading.**

## Still Not Working?

1. **Clear browser cache**: `Cmd+Shift+Delete` (Mac) or `Ctrl+Shift+Delete` (Windows)
2. **Refresh page**: `Cmd+Shift+R` (Mac) or `Ctrl+Shift+F5` (Windows)
3. **Check console**: Press `F12` and look for errors
4. **Check Firestore**: Verify features have correct structure
5. **Retry normalization**: Sometimes a second run is needed
